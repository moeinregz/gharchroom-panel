# قارچ روم — مدیریت یکپارچه شرکت

یک سامانه کامل مدیریت شرکت با React (فرانت‌اند) و Node.js/Express (بک‌اند) شامل:

- داشبورد اختصاصی برای هر نقش (سازنده، مدیر، فروش، حسابداری، سئو، ادیتور، مشتری)
- مدیریت وظایف با قابلیت اختصاص از سمت سازنده/مدیر
- اعضای تیم با اطلاعات کامل و عنوان شغلی
- گفتگوی تیمی + آپلود فایل واقعی + کنترل دسترسی چت توسط مدیریت
- CRM تماس‌ها با خروجی اکسل (CSV) و چاپ
- ثبت سفارش کامل (کمپوست، خاک پوششی، محصولات صنعتی، بسته‌بندی) با کد رهگیری خودکار و فاکتور قابل چاپ
- «مسیر رشد سفارش» — نمایش گرافیکی وضعیت سفارش از ثبت تا تحویل
- حضور و غیاب با ثبت ورود/خروج، قابل مشاهده کامل فقط برای سازنده و مدیر
- یادداشت شخصی برای کارشناس فروش
- گزارش کاری روزانه با نمایش کامل فقط برای مدیریت
- پنل مشتری با سفارش‌های خودش و رهگیری سفارش با کد

## ساختار پروژه

```
company-management/
├── backend/     ← Node.js + Express (پایگاه‌داده به‌صورت فایل JSON، بدون نیاز به نصب دیتابیس جداگانه)
└── frontend/    ← React + Vite
```

## نصب و اجرا

### ۱) بک‌اند

```bash
cd backend
cp .env.example .env      # در صورت نیاز JWT_SECRET را تغییر دهید
npm install
npm start
```

سرور روی آدرس `http://localhost:4000` بالا می‌آید. پایگاه‌داده در فایل `backend/data/db.json` ذخیره می‌شود و در اولین اجرا به‌صورت خودکار با داده‌های نمونه ساخته می‌شود.

### ۲) فرانت‌اند

در یک ترمینال جدید:

```bash
cd frontend
npm install
npm run dev
```

آدرس `http://localhost:5173` را باز کنید.

## نکات مهم پیش از استفاده واقعی (Production)

این نسخه برای راه‌اندازی سریع و آزمایش طراحی شده و از یک فایل JSON به‌عنوان پایگاه‌داده استفاده می‌کند. برای استفاده واقعی و تولیدی پیشنهاد می‌شود:

1. پایگاه‌داده را به PostgreSQL یا MySQL مهاجرت دهید (ساختار جداول از روی `backend/db.js` قابل استخراج است).
2. پروژه را روی یک سرور واقعی (مثلاً با Nginx + PM2) دیپلوی کنید و HTTPS را فعال کنید.
3. مقدار `JWT_SECRET` در فایل `.env` را به یک رشته‌ی طولانی و تصادفی تغییر دهید.
4. اعتبارسنجی ورودی‌ها (مثل کد ملی، شماره تماس) را در سمت بک‌اند تقویت کنید.
5. برای فایل‌های آپلودی حجیم، از یک سرویس ذخیره‌سازی ابری (مثل S3) به‌جای دیسک محلی استفاده کنید.

## گسترش‌های پیشنهادی بعدی

- افزودن اعلان (نوتیفیکیشن) هنگام اختصاص تسک جدید یا تغییر وضعیت سفارش
- امکان تغییر رمز عبور و ویرایش پروفایل توسط خود کاربر
- گزارش‌های تحلیلی و نمودارهای بیشتر برای فروش و CRM
- پیامک/ایمیل خودکار به مشتری هنگام تغییر مرحله سفارش
